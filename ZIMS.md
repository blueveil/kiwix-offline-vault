# ZIM files

30 ZIM files, versions dated 2024-06 to 2026-08. They are not included in this repo. Download them from the [Kiwix library](https://library.kiwix.org) or [download.kiwix.org/zim](https://download.kiwix.org/zim/).

## Reading the file names

File names follow `project_language_selection_flavor_date`.

- `all` means the whole site.
- `maxi` is the full version with images. `nopic` is the same content without images.
- A trailing `a` on the date (for example `2026-05a`) is usually a second build from the same month.
