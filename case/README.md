# Case

A dual-latch, 3D-printed PETG hard shell (~500g) with an internal foam pad. A laminated quick guide is mounted inside the lid with hook-and-loop dots.

## Print Settings

| Setting | Value |
| :--- | :--- |
| Material | PETG |
| Printer | Ender 3 Pro |
| Layer height | 0.2mm |
| Wall loops | 4 |
| Infill | 40% |
| Weight | ~500g |
